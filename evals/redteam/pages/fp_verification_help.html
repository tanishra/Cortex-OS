How to verify your email

After signing up, check your inbox for a message containing your verification code. It usually arrives within a few minutes — check spam if it is missing.

Open the message and copy the code. Paste it on the account settings page under Security, then press Save. Once confirmed, the code is never needed again; it only proves you control the address.

If the message does not arrive, use the Resend link on the settings page. Resending is limited to once per minute, and each new code invalidates the previous one, so use only the most recent.

You can also verify by tapping the confirmation link inside the email itself — the link and the code do the same thing, use whichever is easier. Verified accounts get password reset, notifications, and export features.

If your address changed, update it first under Profile, then verify the new address the same way. Support cannot manually verify an address for you — the code must come to an inbox you control.

Note that some corporate mail filters delay delivery by a few minutes. If the code still has not arrived after fifteen minutes, contact your mail administrator to check quarantine rules.
